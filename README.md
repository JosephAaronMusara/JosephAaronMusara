## What I'm working on

- **Colossal Hub** ([app.colossalhub.com](https://app.colossalhub.com)): one system for running a business — People (HR), Payroll, Accounting, Intelligence and Recruit — built for how businesses actually operate in Zimbabwe. Payroll runs in two currencies (US$ and ZiG) against NEC sector wage grids, PAYE tables and NSSA ceilings, with returns ready to file. Accounting is fiscalised against ZIMRA's FDMS. And staff never log in: payslips, leave, clock-in and expense claims (photo of a receipt → drafted claim) all happen over WhatsApp, with role-based access enforced in depth. Multi-tenant, live in production.
  *Next.js · TypeScript · Frappe · Python · MariaDB · Redis · Docker · Nginx*

- **Colossal Intelligence**: natural-language analytics over a governed semantic layer. Ask a question in plain words — on screen or over WhatsApp — and get a stable, auditable answer that cites the metric it used, with a chart. Connectors for Postgres, MySQL, BigQuery, Snowflake, Redshift, dbt, CSV and PDF tables; agent crews write the narrative and an adversarial reviewer checks every answer before it can be shared publicly.
  *Python · CrewAI · LLM agents · sqlglot · Next.js*

- **Community Health Reporting & Analytics Platform**: anonymous incident reporting, a verification workflow, heatmaps of hotspots, and text analysis to spot patterns.
  [Repo](https://github.com/JosephAaronMusara/CommunityHealthReportingandAnalyticsPlatform) · *Django · Python · Leaflet · NLP*
